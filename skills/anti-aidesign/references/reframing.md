# 根据实拍重设问题

第二阶段从可看的页面开始。先在桌面、手机和实际使用或阅读状态里过一遍。从截图、阅读过程或交互结果指出哪处关系出了岔子，再翻下面的例子。先确定它该让人感到或辨认什么，再决定需要改什么；顺序不按颜色、排版、间距逐栏走。

## 写出可验证的修稿判断

只记一两句：**画面现在做了什么 → 这里应该起什么作用 → 改后怎么认出来**。再指出一处有辨识度、读得顺或用得上的具体关系要留下。先试最能检验判断的局部；如果是构图前提错了，回到创意阶段重开。需要交接的详情留在工作笔记。

可从当前画面触发以下几种修法。碰到别的问题就另找办法。

| 实拍看到的关系 | 可以做什么 | 改后怎么看 |
| --- | --- | --- |
| 标题、列表和状态本应成组，左右边缘或内外间距却让人读成几组 | 在截图或浏览器上拉参考线，量共用边和关键间距，按原来或项目需要的尺度整理。也可拉大间距让确实独立的对象分开。 | 读者一眼能辨认对象和归属。有意的错位如果能带出停顿、视线方向或叙述，保留。 |
| 背景发光、装饰图或通用字把第一眼抢走；或真正的信号在画面里太弱 | 暂时去掉这份强调再看，把注意力还给作品；必要时把主物做大、加强对比、增加颜色或补一个明确的辨认线索。 | 关键对象和状态更早被看到；有区分作用或表达作用的颜色、图形与节奏保得住。 |
| 金额、变化、状态旁找不到它的对象、时间或比较期 | 用已有事实把口径贴回对应的值或状态。缺事实时别补猜测；重排、标明数据缺口或用适合的表达。 | 实际读出是什么、属于谁、何时发生、和什么比；同一记录在手机、桌面或交互结果上保持同一含义。 |
| 作品因为一味求齐、求干净而失去力气 | 让有意义的拥挤、反差、错位、停顿或笔迹恢复它在作品里的位置；调整邻近部分让它更好发生。 | 具体哪个字、哪一段或哪次切换重获原有的表现力；主体之外的东西没有跟着抢眼。 |

[Ember 的视频示例](field-notes.md)把量边线、降掉多余的发光和补比较口径用在同一个财务界面，保留了表达数据类别的颜色。用它练习从证据挑动作；它的深色、密度和图表样式来自那张画面。改完用同样的素材、数据和状态再看；发现没有赚到阅读、表达或使用上的好处就还原。交付条件另见[浏览器验收](render-gate.md)。
