# 画面材料：先决定拿什么做构图

适用于承担首眼、身份、辨认或主要情绪的东西。先看实际内容和可用素材，再决定页面要不要留图的位置。记录一条可核对的决定：它是什么、从哪来、在此处让人看出什么；缺它时画面由什么承担。用户指定、品牌批准和设计师交付的素材优先。

## 按图形承担的工作选媒介

| 屏幕上的信号 | 具体处理 | 打开页面验收 |
| --- | --- | --- |
| 场景、产品、包装、人物、地点或纸张、木料、织物、金属的细节，在承担身份或物质感 | 拿已提供、经授权或明确许可的真实照片、档案、产品图、纹理；样张注明其用途。接受适合用途的原创插画、生成的概念图，按概念图使用。没有对应资产时，用原文、可核对属性、真实截图、实际状态或另一种构图撑住页面。 | 用实际尺寸和手机裁切，看得清关键细节；出处、主体和用途对得上。具象样张不冒充具体店面、人物、SKU、建筑、证照、使用证据或实拍。 |
| 用 CSS 层叠、内联 SVG、Canvas 滤镜、渐变、网点和噪声拼出「照片感」「纸感」或三维物体 | 去掉依赖这种仿真的画面。确需该物件或材料，换项目适配的真实／获准素材；画面仍成立时让空间、真实字、色彩关系或功能状态承担原来那部分。检查纸粒、光晕、高光在耍同一套把戏时，连同大图占位一起重排。 | 暂时隐藏旧图及其占位看一眼，再对照素材版。两端确认没有补成另一张与业务无关的大图、发光渐变或批量重复的合成小物。换成 PNG 或转用图生工具，仍按同一标准验收。 |
| 自绘医院楼、蓝图零件、风景或包装只是给通用横幅占位 | 拿一个真实任务状态做独立粗稿，如可选的号源、同 OE 的几项差别；再与另一种成立的开场（有素材可试、也可直接用字或色）并看。保留有实用作用的图，例如入口实景帮人找路。 | 检查手机首屏哪个对象先被看到，真实数据／操作有没有被下推；必要插图无需强行缩小。 |
| 头像槽塞姓氏或临时自绘人物，品牌位塞随手生成的标记 | 有项目给的头像、识别标志就用；没有时，用姓名、角色、机构全名或认真排过的文字署名。群组身份由顺序、分组和标签辨认。 | 去掉占位图后仍能认人、辨认来源或返回主页；有身份凭证的图用实际来源。 |
| 是图表、可操作地图、示意、图标、排版或明确属于作品的抽象图形、动态和画笔 | SVG、CSS、Canvas、文字都可用。先写它具体编码的东西，如号源、字的衰减、比例、路径、对照或时间。主动选择形状、粗细、节奏和取舍。具象的手绘也可以成立，前提是它作为插画的选择在作品里有意义。 | 实际走一次变化。遮图后失去哪条信息或哪段感觉？能用实际对象回答，就保留这项表达。可读文本、键盘或减少动态的路径照任务准备。 |

## 识别同一图位换了画法

- 看一眼原图从画面上拿走后发生什么：用户少辨认了一件东西、少看懂一个变化，还是少了一个印着品牌联想的装饰？例如名叫「暮山」所以画山和夕阳，只复述了名词；给咖啡准备素材时，实际要看的是豆、冲煮或可选品项。如果一张泛图放在同一格仍能替代它，先做一次**没有这块图也没有旧容器**的重排。
- 若主图是这次去 AI 味的核心，在浏览器真的看两份首屏小样：直接用内容／动作起稿，以及确有价值的素材或不同读法。没有合适图时第二稿可用别的文字节奏、空间或交互关系。两边可用同样的内容；尺寸、阅读次序或先看到的对象应产生区别。选前说清两稿各牺牲什么。
- 给清楚的艺术例外：如果这张图承担画面叙事，能指着具体构图或某帧说出它怎么改变情绪，就能保留。不靠「风格化」「概念图」给占位合理化。给静态作品留点表达空间，模型可以试光灭的一拍、字退到视野外、窗口一样的留白，另有必要才画实体场景。

## 素材落地

- 从项目资产、可拍摄的实物或可许可原档找。先核对权属、作者、用途、主体和可改动范围，再接入。通用资料照放在它能说明的语境；商品照要对应商品，案例照要对应案例。需要注明的署名放在图源、鸣谢或素材记录。
- 素材缺失时，纯表达作品可以让留白、字的尺度、移动、构图、色场或读者的动作发挥作用；不要给每件作品都配场景照。同理，有功能的页可直接用工作材料开场。避免把「无图」顺手做成另一套暖米白、线框和大标题。
- 新建视觉方向时，先看旧图去掉后应该怎么排，再做另一张有不同主材料或不同读法的粗稿。两张首屏用相同的真实文字或数据；回看桌面、手机及实际操作或作品状态。如果只是同一个位置里换图，接下来要改的是构图。
- 检查图像文件实际加载、裁切、对比度和文字替代。完全装饰的图给空 alt；传达信息或功能时写它传递的内容或动作。无关的制作说明写在工作纪录里。

可参照 [GOV.UK 图片指南](https://design-system.service.gov.uk/styles/images/)、[IBM Design Language 摄影选用](https://www.ibm.com/design/language/photography/overview/)及 [W3C 图像替代文字](https://www.w3.org/WAI/tutorials/images/)。结合页面场景取舍。
