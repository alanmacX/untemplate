# 练习审美判断：看，动一下，再看

适用于开放 brief、现有作品的视觉诊断，或画面又变成熟悉模板时。挑能改变作品的一两个判断来试。先在屏幕上看到它们，再把结论带进代码。

## 第一眼与余味

想象一个具体的观看时刻：地铁里扫一眼、面对大图移近、夜里把一段话读完、在画面里漫游。让期待的感受有可见的依据。安静可以来自一个留有呼吸的主角和克制的间距；亲密可以来自更近的裁切、适中的字级和细密的关系。实际素材也可能给你一个更好的理由，允许改原来的设想。没有业务任务的作品可以让这一刻本身作为设计依据。

连想要什么感觉都没定时，从现成的材料做一个好奇的试排。让看过的画面逐渐给出方向，保留有意思却还说不清楚的余地。

## 用真实材料选择关系

- **重心。** 缩小看，先认出来的是什么？如果短句和图都大，选择让其中一个前进。检查最亮、最大或最重的部分有没有承担这份关注。
- **距离与节奏。** 看什么贴着什么、视线何时换方向、在哪儿停。可试相邻和隔开、连续和留白、同时出现和先后出现。疏密本身会塑造气质；留白能让两处相互牵引，也会让原本相干的东西看成两页。
- **统一里的变化。** 找可反复沿用的联系，比如对齐边、色温、文字密度或形状的呼应。给实际需要被辨认、慢读或强调的地方一个例外。统一不必把每块装进同一种盒子；有意的变化也不必处处惊吓读者。
- **材料的性格。** 选实际图片、数字、笔画或空间作为视觉依据。先看这种材料自然带了什么气质，再定字体、对比和外框怎么与它共处。既能用极简、静止和系统字，也能用高饱和、密排和大胆的字。画面里的漂亮细节可以只承担表达，只要能指出它在这里为什么值得留下。

## 看小样时发现一个新问题

先别读自己的设计说明。把小样在实际视口里看一眼，指出一处你原来没预料的关系，或者一句原判断仍然成立的证据。改一个选择，比较桌面、手机和需要的阅读或操作状态。可以临时换一个裁切、尺度、留白或者字重来试；用结果决定要不要还原。需要交接时只留下可核对的一两句，比如「字号进一步收，腾出的空间让第二句落到下一段，先看第一句」。

看参考时也练这一遍：[Endless Horse](https://secure.endless.horse/)用滚动延续同一个玩笑；[Cameron’s World](https://www.cameronsworld.net/)用原本嘈杂的 GeoCities 片段造出漫游气质。它们提供不同的组织和表达方法。素材许可和必要的可访问性按项目落实。

依据：[Schön 与 Wiggins：设计中的几种看法](https://www.sciencedirect.com/science/article/pii/0142694X9290268F)、[Suwa 与 Tversky：建筑师如何从草图看到关系](https://chi1996.acm.org/proceedings/shortpap/Suwa/sm_txt.html)、[Hekkert：设计审美中的统一与变化等原则](https://pure.tudelft.nl/ws/portalfiles/portal/54686438/Hekkert_P._Design_aesthetics_principles_of_pleasure_in_design.pdf)、[Andy Clarke 谈通过布局、文字和颜色表达](https://www.smashingmagazine.com/2019/11/smashing-podcast-episode-1/)。用这些办法观察当下画面，不把它们做成打分表或固定风格。
