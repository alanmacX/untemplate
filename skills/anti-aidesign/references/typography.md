# 中文与多语排版

当几页总用相似的标题、正文和小字搭配，或临近交付要检查字体时读。挑字的单位是一组同屏出现的真实文字。

1. **找文字的工作。** 现场办事先认名称、状态、价格、时间、限制；长文先让眼睛找得到下一行；作品和品牌可让文字参与构图。决定哪里需要显眼，哪里需要持续读，哪里需要快速区分字符。标题允许自然地贴着作品、记录或控件，小字为实际有用的标签服务。
2. **先打破第一稿的字体角色，再选字体。** 放入同一条长标题、两行最容易看错的记录（若有）和关键动作或作品原句。标出第一稿默认加重了什么；另排一稿，把最强的位置、字重或留白让给别的真实文字，改变读序或节奏。用桌面和手机实际渲染这两段，可以只做最有影响的一屏。只换字库、大小写或把同一标题缩一号，要继续重排。常见字体只要适合当前角色就能留；两稿可以共用同一字体。
   - 办事、查询或比价：试着让下一步要核对的对象比页面大标题更先读到。拿两个真实产品名、长型号、金额或日期看看一眼会混淆哪两个。
   - 品牌或作品：试正文带节奏、现有字标、地名或一句确实有内容的文字来带首眼；可试同一主题自然长短、疏密和停顿的排法。说明哪份更合适用具体读到的对象或句子作证。
3. **看浏览器真正用了什么。** 检查声明和实际字形；字体文件失败、系统回退或缺字时，标题、状态和按钮仍要易读。开源或品牌字体沿用其许可和范围，没必要加载字库时用可读的系统选型。中英混排也检查实际字面大小、基线和数字，不用装饰性字样替代翻译或标签。
4. **桌面、手机各验一次。** 用真实内容查第一眼看见哪一行、关键条件是否挤到操作下面、排版是否可换行。再用窄屏或放大文字和改间距检查标签、表格、状态和按钮有无隐藏、重叠或失效。核对有意义的对比度和字形区别，关键区别应通过文字和位置也能辨认。

## 让字库真实参与选择

字体是用户点名的重点、字承担作品气质或信息辨认、或者多页的字体开始雷同时，先把排法按住，直接试字库：

1. **收三个有机会赢的候选。** 把初稿的真实字体当一组，另找至少两套字形差异可说清、可能适合这个角色的候选。从项目字体、环境字体、作者或维护方许可的字库找。用字面宽窄、笔画密度、行文节奏、数字或符号形状决定搜什么；可在同一大类里比较一宽一窄、端正和有笔势的字。先看内容再定候选，也别把上一题胜出者直接带到下一题。用户或设计系统已指定字库时，沿用指定系统；素材或授权受限时，在可用范围比较真实候选。
2. **同字、同角色、同字号实拍。** 保持同一列宽和文字，先看字形、内白、字面大小、行尾和数字差异，再允许做光学校准。让候选各自成为首选并确保真实生效：看 Rendered Fonts、PostScript 字面或等效浏览器信息，核对确实覆盖该段中文。写在 fallback 后面的字、落到同一字面的权重、只改拉丁而汉字没换的组合，都不会给中文字形新增候选。记录实际用字和一个可见取舍，再用胜出的字检查真实的行宽、字号和移动端。
3. **部署只带入合适的字。** 根据使用场景核对授权、目标环境、字形覆盖、传输和回退。标题、长读、型号分别可以有理由地选字；同一站用一套字号与字面关系也成立。跨项目颜色和图变了，文字形状仍重复时，回到真实候选重新取样。

找样本可从维护方出发，例如 [Adobe 思源字体](https://blog.adobe.com/en/publish/2021/04/08/source-han-sans-goes-variable)、[朱雀仿宋](https://github.com/TrionesType/zhuque)、[霞鹜文楷](https://github.com/lxgw/LxgwWenKai)、[得意黑](https://github.com/atelier-anchor/smiley-sans)。按字形和用途找，以上名称只作起点。

## 中文页面按中文做一轮

- **先让浏览器选对文字。** 按简繁和实际地区设 `lang`，例如 `zh-CN`、`zh-TW`、`zh-HK`；有明确地区需求时选相应字形，局部其他语言标到那段。系统字体和地区版开源字库都可作为候选；用浏览器的 Rendered Fonts 确认汉字、标点、拉丁字母、数字与生僻字最后分别落到哪套字。正文、状态、按钮的视觉一致比统一写一个 `font-family` 更重要。
- **把可读性与美观都看在同屏。** 短时间扫读关键状态时看复杂字的笔画是否挤满、细横是否消失；长文看行宽、行距、阅读节奏和翻行。展陈标题、品牌字或场景性文字可以鲜明，位置和字形应与实际材料有关。拿大标题、数字密集记录和普通段落分别试合适的字体与字重；黑体、宋体或其他字形是候选，不是固定组合。拉丁标题的紧负字距不要原样套到中文。
- **用实际长文本、金额与时间试换行。** 看中文标点有没有掉到不合适的行头行尾，书名号和括号能否贴住内容，`¥128`、`15:30`、中英混合的产品名和数字单位是否仍成组易读。数字要比较的一列可用等宽数字；整页不必等宽。到 320px 窄屏、放大和回退字体状态都复看关键条件和控件。
