# 排版与字体靠实际使用来定

当几页总用相似的标题、正文和小字搭配，或临近交付要检查字体时读。挑字的单位是一组同屏出现的真实文字。

1. **找文字的工作。** 现场办事先认名称、状态、价格、时间、限制；长文先让眼睛找得到下一行；作品和品牌可让文字参与构图。决定哪里需要显眼，哪里需要持续读，哪里需要快速区分字符。标题允许自然地贴着作品、记录或控件，小字为实际有用的标签服务。
2. **用内容比两种排法。** 固定布局关键关系，放入一条长标题、最可能看错的两条记录、一个操作和操作结果。对照字宽、字号比、字重、行距和换行，再决定需不需要另一套字。改变一项后看是否让名称和条件更易区分、信息更顺着读，或能让具体材料有更贴合的气质。常见字体在合适的角色上可以用；不用「高级」预选展示衬线加无衬线正文，也不把巨标题、极紧字距或全大写标签作为默认配套。
3. **看浏览器真正用了什么。** 检查声明和实际字形；字体文件失败、系统回退或缺字时，标题、状态和按钮仍要易读。混排用真实语言和标点测试。中英混排注意两套字的视觉大小、基线、数字与单位、中文断行；需要按列比较时试等宽数字，普通叙述随字体自然排。开源或品牌字体沿用其许可和范围，没必要加载字库时用可读的系统选型。
4. **桌面、手机各验一次。** 用真实内容查第一眼看见哪一行、关键条件是否挤到操作下面、排版是否可换行。再用窄屏或放大文字和改间距检查标签、表格、状态和按钮有无隐藏、重叠或失效。核对有意义的对比度和字形区别，关键区别应通过文字和位置也能辨认。

参考：[IBM Carbon 的实用／表达排版](https://www.carbondesignsystem.com/building-blocks/foundations/typography/style-strategies)、[W3C 中文排版需求](https://www.w3.org/TR/clreq/)、[WCAG 文本间距](https://www.w3.org/WAI/WCAG22/Understanding/text-spacing.html)和[窄屏重排](https://www.w3.org/WAI/WCAG22/Understanding/reflow.html)。借规则解决本项目的问题，按实际语言和密度取用。
