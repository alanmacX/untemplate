# 给已有作品去 AI 味

1. **先打开用户给的版本。** 看桌面和手机、开头和结束，有交互也实际点一次。找值得保留的事实、声音、图像、视觉特点、阅读节奏和可用功能。明确喜欢的部分当成设计约束；用现有文案和资产做比较。
2. **用原版重新判断。** 按[重设问题](reframing.md)读实拍，描述实际第一眼看到的画面：哪儿被套了横幅、同样的标题搭配和卡片反复到哪儿、什么内容被挤小、什么颜色或字让作品有不合场景的语气。圈出一处影响最大的关系。别按 CSS 类名或视觉元素黑名单删东西。
3. **按实拍证据决定修法。** 先用临时小样检查一个改动。例如去掉介绍框以后，主体能不能直接成为开场；两张图并看时，注记可不可以并入图旁而只留一处署名。大结构本身妨碍作品时，回到阶段一试另一种构图；把用户认可的旧版部分随新稿一起带上。检查有没有无意中改掉正文、状态、数据和交互。
4. **原版和改版在同一条件一起看。** 核对保留项和需要消失的 UI 文案。只观看的作品按实际阅读及体验复看，具体说出改完哪里更有力、哪里更平庸。功能页走同一条主流程；设计师给定的方向和受保护的细节照原要求验收。
