# 从实物和任务开稿

当 brief 只给了感觉，或候选只是在同一种高级感里调颜色时读。作者的取舍可以很实用，也可以很有表现力。先找这页打算让人仔细看、快速扫读、拿去核对或实际操作的东西。

## 用材料做小样，留住使用时刻

- 把一份够真的内容放进去：例如已有回执里两个容易混淆的时间，或者图档里的完整纸边、笔迹和比例。把操作前后放在旁边看，找一条能改变设计的问题。先排可用的小样，再补页头和页尾；小样也可以本身就是整屏。
- 把场景用到具体决定里。人在街上确认取件，时间要贴着对应取件点；同一张回执可做主画面。人在看插画，首屏可以并排给两个对象，也可以让一幅画占住屏幕，让人看清纸边。预览两种各会牺牲什么。例子用于启发，换项目就换材料和取舍。
- 别用行业符号填补没有决定的地方。冲扫点可以用胶片或排字表达气质，先问哪里真需要辨认那卷胶片，哪里只是要扫一眼取件。缺真实照片时可靠现成回执、数字、标记和实际语言组织画面。需要图片时，找对这件事有用的真实或授权素材；有意的插画、字形也可以成为主体。

## 看真人页面怎样解决这个问题

找至少一个有真实运营、阅读或操作的页面。看一张首屏，再跟一个链接或操作进到实际任务。找它的材料、取舍，以及这个取舍受到什么约束；把能用的关系带回自己项目。不用把多个站的招牌风格平均成一种中性风格。

- [The Creative Independent](https://thecreativeindependent.com/)把色块变成当天可读的记录；从[作者的设计记录](https://laurelschwulst.com/e/tci-website/)可见她从采访本身及其链接向外组织。高饱和度和强边框在这个内容索引里有地方用。
- [Edinburgh Tool Library 的库存](https://edinburgh.myturn.com/library/inventory/browse)实拍物品，按地点和库存筛，回归日或可借状态跟在物品旁。能用常规卡片，因为要反复比较的是物品。
- [justfont 金萱](https://justfont.com/jinxuan/)把字放大给人直接看笔画，也让同一字型落到读得下去的正文里。中文视觉依据可以是具体字的结构；测试项目的字，见[中文与多语排版](typography.md)。

## 收口时复查画面

比较两端首屏及结果时，指出材料是否还占着应有的位置，变化后什么留在手边。若先后和比例已经不同，字体、底色、间距却依然自动落回同一套成品语气，分开画一版表面：随实际素材试背景承托、字的重量、信息密度和节奏。选对当前对象有益、而且整体好看的表达。用[文案门槛](copy-gate.md)清掉为填版面而写的字。
