# 删除没有独立信息的短文案

把这条验收直接交给写代码或精修的人。设计计划、实现交接、最终 DOM 都应用。放行标准是用户实际看到的页面和状态里没有这类残留。

检查对象是生成的多余界面文案。用户正文、署名、作品为节奏有意使用的反复和图上的实际文字都按作品完整保留。

1. **不要先造槽。** 从标题和实际字段出发。英文类别词、重复品牌副标、序号加栏目、图里或 CSS 边上附的短句都用同一套判断。导航已准确表述当前任务时，不需要再造一套醒目标题和附属词。保留屏幕阅读器可辨认、与内容层次相符的语义标题；允许同一个主要标题同时承担视觉辨认。
2. **遮一次再判断。** 按桌面和手机实际读序，从页头查到页尾，包含列表上方、卡片、空状态、抽屉和主要结果。暂时移走该短句，问哪条信息或必要线索消失。答不出来直接删；只少了一点必要信息时把它并到标题、对应字段或动作。需要翻译时由本地化切换或按明确的双语受众需求设计。
3. **改 DOM 和空间。** 删实际节点、模板输出、重复的翻译或伪元素；收掉只给它的空槽和间距。检查可访问名称和 `aria-labelledby` 仍指向保留的标题，关键短句在正确控件附近。用真实点击抵达结果状态再复核。

| 看到的文案 | 修法 |
| --- | --- |
| 「工具借用」上方再写 `TOOL LOANS`，或者品牌名下跟着可贴到任意同行的口号 | 保留一次实际任务或品牌名。 |
| `LOAN TERMS` 紧跟「三天」 | 合成「可借 3 天」，贴着借用状态和自提时间。 |
| 地图标题旁重复写「果园地图」，在同区还分别写「北区封闭」和「北区泥泞暂封」 | 删地图的重复装饰标签；把状态与原因写一次，贴着北区。 |
| 「不收押金」「周六 15:30 截止」「仅供演示」 | 承担真实条件、限制或状态，留在用户做决定的位置。 |

用[浏览器验收](render-gate.md)的 `drop` 对照已判定该删的确切节点。颜色、大小、全大写和类名只是定位线索，判断看短句承担什么工作。完成后在手机首屏、长页末尾和结果状态再看一眼；仍有一处空标签就继续修。
